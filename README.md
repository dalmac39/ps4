# DALMAC PS4 — Offline Web Host & Systems Research Platform

منصة ويب متقدمة ومستقلة بالكامل (Offline-First Host) صُممت للعمل مباشرة على متصفح جهاز PlayStation 4. يقوم المشروع على هندسة برمجية منخفضة المستوى (Low-Level JavaScript) تجمع بين استغلال ثغرات بيئة تشغيل WebKit، وإدارة الذاكرة عبر سلاسل ROP، وتحميل الحمولات البرمجية الثنائية (Payload Staging / GoldHEN)، مع توفير واجهة تحكم متكاملة مخصصة ليد التحكم ومجهزة للعمل دون أي اتصال بالإنترنت.

## 📌 أبرز الجوانب الهندسية (Engineering Highlights)

- **معمارية العمل غير المتصل (Dual Offline Strategy):**
  - دعم مزدوج لتقنية `Application Cache (cache.appcache)` للتوافق التام مع متصفح WebKit الخاص بالنظام القديم.
  - دعم `Service Worker` باستراتيجية **Cache-First** للتخزين والتحديث التلقائي لكافة الحمولات والملفات الثنائية محلياً.
  - جاهزية العمل كـ Progressive Web App (PWA) عبر `manifest.json`.

- **إدارة الذاكرة والحسابات الثنائية (Low-Level Memory Primitives):**
  - بناء دوال قراءة وكتابة الذاكرة الحرة (Arbitrary Read/Write Primitives) باستخدام `ArrayBuffer` و `DataView`.
  - معالجة المؤشرات وعناوين الذاكرة 64-bit بواسطة وحدة حساب مخصصة (`int64.js`) دون الاعتماد على مكتبات خارجية.
  - بناء سلاسل ROP (Return-Oriented Programming) لتجاوز قيود بيئة العزل (Sandbox Escapes) وتوجيه التدفق التنفيذي لنواة النظام (Kernel Space).

- **مصفوفة الإزاحات الديناميكية (Dynamic Offsets Matrix):**
  - فصل منطق الإزاحات البرمجية عن المحرك الأساسي عبر وحدة `ps4_offsets.js`.
  - التحقق التلقائي من الحقول الإجبارية والاختيارية لكل إصدار نظام قبل بدء التنفيذ لمنع تعليق النظام (Kernel Panics).

- **معالجة غير متزامنة عبر (Web Worker RPC):**
  - تفريغ العمليات الحسابية والمسح الموجه للذاكرة إلى مسار خلفي مستقل (`rpc_worker.js`) لتفادي تجميد واجهة المستخدم (UI Thread) أثناء التهيئة.

- **التكامل العتادي والصوتي بدون أصول خارجية (Zero-Asset Hardware Integration):**
  - دعم كامل لواجهة التحكم بالأجهزة **Gamepad API** لقراءة إشارات يد التحكم (DualShock 4) ورسم تلميحات الأزرار ديناميكياً.
  - توليد المؤثرات الصوتية التفاعلية برمجياً في الوقت الفعلي عبر **Web Audio API** (Oscillators & Gain Nodes) دون تحميل أي ملفات صوتية خارجية.

│   ├── 1302.bin
│   ├── 1350.bin
│   └── 1352.bin
└── assets/               # الهوية البصرية وخلفيات واجهة المستخدم

## 💻 التشغيل والنشر المحلي (Setup & Local Deployment)

المشروع مصمم ليعمل كـ Static Web Application دون الحاجة لأي خادم معالجة خلفي (Serverless / Static). يمكن استضافته على أي خادم ويب ثابت خفيف أو استضافته محلياً للتجربة:

### 1. الاستضافة عبر Python:
```bash
# تشغيل خادم محلي على المنفذ 8080
python -m http.server 8080
```

### 2. الاستضافة عبر Node.js:
```bash
npx serve -l 8080 .
```

### 3. التخزين الأوفلاين داخل الجهاز:
- بمجرد زيارة المتصفح لرابط الاستضافة لمرة واحدة، يقوم الـ `Service Worker` و `Application Cache` بتحميل كافة المكونات في الذاكرة التخزينية للمتصفح.
- يمكن بعدها قطع الاتصال بالشبكة تماماً وتشغيل الواجهة عبر سجل المتصفح أو الإشارات المرجعية (Bookmarks).

## 🛠️ التقنيات والمهارات المطبقة في المشروع (Competencies Demonstrated)

- **هندسة النظم وتتبع الذاكرة (Systems Engineering):**
  - فهم متعمق لآليات عمل محركات المتصفحات (WebKit Internals)، وتجاوز حماية الذاكرة (DEP/ASLR) عبر ROP Chains.
  - التعامل مع الـ Endianness، وتمثيل البيانات الثنائية في الذاكرة (TypedArrays, DataView, ArrayBuffer).
- **تصميم تطبيقات الويب عالية الأداء (Modern Web Architecture):**
  - تطبيق مفاهيم Offline-First بدقة باستخدام Service Workers واستراتيجيات Caching متقدمة.
  - الاستفادة من الـ Multi-Threading داخل المتصفح عبر Web Workers.
- **تطوير واجهات المستخدم الموجهة للأجهزة الترفيهية (Console UI/UX):**
  - استغلال الـ Gamepad API لتقديم تجربة تحكم أصيلة مشابهة لنظام تشغيل الجهاز.
  - بناء واجهة ثنائية الاتجاه (RTL/LTR) بتصميم Cyberpunk عصري وعالي الأداء بدون أطر عمل ضخمة (Vanilla JS & CSS).
